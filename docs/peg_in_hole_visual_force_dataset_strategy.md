# 孔插入任务的视觉泛化与力反馈纠正数据集设计

## 1. 目标与核心结论

孔洞位置、纹理和光照等随机化，主要用于增强模型的视觉定位与视觉泛化能力。它们本身不一定能显著提升模型根据力反馈在线调整动作的能力。

如果希望模型学会利用力/力矩反馈进行接触后的动作纠正，数据集必须包含更丰富的接触状态，以及接触发生后明确、连续且有效的恢复动作。所需数据并不是简单的“更多碰撞”，而是：

> 更丰富、可恢复、带有明确正确响应的接触交互数据。

理想的数据应完整覆盖以下因果链：

```text
动作或位姿偏差
    → 产生特定接触与力/力矩变化
    → 根据反馈执行修正动作
    → 接触力减小或接触状态改善
    → 最终成功插入
```

## 2. 视觉随机化和接触随机化的区别

不同类型的孔洞随机化，提升的能力并不完全相同。

### 2.1 主要增强视觉泛化的随机化

- 孔洞在图像或工作空间中的位置；
- 孔洞颜色、纹理和材质外观；
- 光照、阴影和相机噪声；
- 背景和遮挡；
- 相机视角。

这类数据主要帮助模型回答：

> 孔在哪里，末端相对于孔处于什么位置，应该如何接近和粗对准？

### 2.2 同时改变接触动力学的随机化

- 孔径和装配间隙；
- 孔口倒角；
- 孔和插销的形状；
- 接触刚度；
- 摩擦系数；
- 孔的倾角和深度；
- 工件质量及装配公差。

这类随机化除了影响视觉，也会改变接触模式和力反馈，因此有助于提升力控泛化能力。

## 3. 接触交互数据应该覆盖什么

### 3.1 初始误差

- 不同方向和幅度的平移误差；
- 横滚、俯仰和偏航误差；
- 不同的接近方向和接近速度；
- 不同插入深度处产生的误差。

各方向应尽量对称覆盖，避免只采集某一个方向的碰撞与纠正。

### 3.2 接触模式

- 轻微擦碰；
- 单边接触；
- 双点接触；
- 孔口正面碰撞；
- 斜插；
- 边缘滑动；
- 插入中途摩擦增大；
- 卡住或楔紧；
- 接近安全力阈值、但仍可恢复的碰撞。

应以安全、可恢复的接触为主，而不是盲目增加碰撞强度或不可恢复状态。

### 3.3 恢复动作

- 侧向平移重新寻找孔中心；
- 小角度旋转重新对准；
- 降低下压力；
- 短距离回撤后重新接近；
- 沿孔口滑动或执行局部搜索；
- 从卡住状态中解脱后再次插入。

每类碰撞都应尽量记录完整的“接触建立—动作调整—接触改善—成功插入”过程，而不只是碰撞发生的瞬间。

### 3.4 物理和传感条件

- 接触刚度、摩擦和间隙；
- 力/力矩传感器噪声；
- 零点漂移；
- 反馈延迟；
- 不同末端负载；
- 不同工具姿态下的重力项。

## 4. 怎样让模型真正学习使用力反馈

仅仅在数据中记录力，并不代表模型会使用力。若操作者每次都依靠视觉或固定动作模板完成恢复，力反馈可能只是一个与动作无关的附带信号。

数据应有意识地包含以下对比：

1. 视觉观测近似相同，但接触力方向或大小不同，对应不同的纠正动作；
2. 力反馈相似，但机器人姿态或接触几何不同，对应不同的动作；
3. 同一失败状态附近的错误动作与正确动作对比；
4. 接触发生前、接触建立、纠正中、脱离接触和插入成功的连续过程；
5. 正常无碰撞插入与碰撞恢复数据，防止模型学成持续搜索或频繁回撤。

训练采样时，可以适当提高以下片段的权重：

- 接触刚刚建立；
- 力/力矩发生突变；
- 恢复动作开始；
- 卡住状态被解除；
- 恢复后重新成功插入。

这样可以避免大量无接触运动片段淹没真正关键的接触决策数据。

## 5. 孔位是否应该固定

建议在力反馈学习的早期阶段固定孔位，但不要在全部训练过程中始终固定孔位。

### 5.1 固定孔位的价值

固定孔的位置和姿态，可以减少视觉定位误差这一混杂因素，使模型更容易先学清楚：

> 某种接触状态或力矩模式，对应什么方向和幅度的纠正动作。

在固定孔位阶段，仍然应该充分随机化：

- 末端初始位置；
- 末端初始姿态；
- 接近方向；
- 接触方向；
- 接触深度和强度；
- 恢复动作类型。

### 5.2 固定孔位的风险

如果孔位、起始末端姿态和接近轨迹都近似固定，模型可能直接记住以下捷径：

- 世界坐标下应该朝哪个方向运动；
- 某组关节角对应哪个固定动作；
- 某个时间点应该执行回撤或侧移。

此时即使模型表现良好，也不能说明它真正读取了力反馈。

因此，即便孔位固定，也应随机化初始末端状态，并覆盖各方向的接触和修正。更稳妥的做法是让孔位存在小范围抖动，而不是完全不变。

### 5.3 从固定孔位过渡到孔位随机化

模型能稳定完成固定孔位下的接触恢复后，再受控改变：

- 孔的平面位置和高度；
- 孔的朝向和倾角；
- 孔的间隙、倒角和摩擦条件。

开始时最好一次只改变一到两个因素，从而判断性能下降来自视觉定位、坐标变换还是接触动力学变化。最后再进行多因素联合随机化。

## 6. 坐标系设计

同一种“向孔中心纠正”的动作，在不同孔位和孔姿态下，对应的世界坐标动作可能完全不同。因此，训练标签和输入特征最好尽量转换到任务相关坐标系，例如：

- 孔坐标系；
- 末端工具坐标系；
- 由视觉估计得到的局部任务坐标系。

力、力矩和动作增量应使用一致且定义清晰的坐标系。这样可以减少模型对绝对世界坐标的依赖，并提高接触策略迁移到新孔位时的泛化能力。

## 7. 推荐的分阶段训练方案

可以采用两个主要学习阶段，但建议在最后增加一次联合微调。

### 7.1 阶段一：学习视觉定位与视觉泛化

这一阶段使用孔洞位置变化范围较大的数据，重点随机化：

- 孔的位置和姿态；
- 孔的外观；
- 光照和背景；
- 相机视角；
- 末端相对孔的初始位置。

数据以无接触接近和粗对准为主，同时保留少量简单接触数据，避免模型形成“视觉变化数据中永远没有接触”的错误关联。

主要训练：

- 视觉编码器；
- 孔和末端相对位姿表征；
- 接近与粗对准策略。

该阶段希望模型学会：

> 在不同视觉条件和孔位下找到孔，并将末端移动到合理的接触前状态。

### 7.2 阶段二：学习基于力反馈的纠正

这一阶段可以主要使用固定孔位或小范围孔位变化的数据，并密集覆盖不同接触模式和恢复动作。

建议的数据设置是：

- 孔位固定或只做小范围抖动；
- 末端初始位置和姿态大范围随机化；
- 接触方向、强度和模式充分变化；
- 每个碰撞状态都有明确且成功的恢复示范；
- 混入约 20%～40% 的第一阶段数据进行回放。

训练时可以采用差异化更新：

```text
视觉编码器：冻结，或使用约 0.1 倍基础学习率
力觉编码器：使用正常学习率
多模态融合模块：使用正常学习率
动作预测头：使用正常学习率
```

如果完全冻结视觉编码器，需要先确认第一阶段的视觉特征不仅能识别孔，还能表达末端相对孔的位姿关系。否则，融合模块可能缺少完成接触纠正所需的空间信息。

### 7.3 阶段三：联合微调

最后使用较小学习率，将视觉泛化数据和接触恢复数据混合进行短时间联合训练。数据应同时包含：

- 大范围孔位变化下的无接触接近；
- 大范围孔位变化下的接触恢复；
- 固定或小范围孔位下的密集接触恢复；
- 顺利插入和碰撞后恢复插入。

联合微调用于连接“视觉找到孔”和“接触后根据力纠正”两种能力，并减小两个训练阶段之间的数据分布断层。

## 8. 参考数据配比

可以从下面的配比开始，再根据验证结果调整：

| 训练阶段 | 视觉泛化数据 | 接触恢复数据 |
| --- | ---: | ---: |
| 阶段一：视觉学习 | 80%～90% | 10%～20% |
| 阶段二：力反馈学习 | 20%～40% | 60%～80% |
| 阶段三：联合微调 | 约 50% | 约 50% |

从全数据集采集量角度，也可以先参考：

- 40%：固定孔位，密集覆盖各种接触和恢复；
- 40%：多个离散孔位，重复覆盖相同的接触模式；
- 20%：连续随机孔位和多因素联合随机化。

这里的比例不是固定规则。若模型视觉定位仍不稳定，应提高视觉泛化数据占比；若定位准确但碰撞后无法恢复，则应提高高质量接触恢复片段的占比或采样权重。

## 9. 需要重点防范的问题

### 9.1 灾难性遗忘

若第二阶段只使用固定孔位接触数据，模型可能丢失第一阶段获得的视觉泛化能力。

缓解方法：

- 在第二阶段回放第一阶段数据；
- 冻结视觉编码器或降低其学习率；
- 最后进行联合微调；
- 在每个训练阶段持续测试未见孔位。

### 9.2 模态捷径

模型可能根据绝对坐标、关节角、固定轨迹或时间进度预测动作，而忽略力反馈。

缓解方法：

- 固定孔位时随机化末端初始状态；
- 为相似视觉构造不同力反馈和不同动作响应；
- 对输入模态进行消融或遮蔽测试；
- 使用局部任务坐标表达动作和力；
- 将固定孔位改为小范围孔位抖动；
- 避免每种碰撞都使用完全相同的恢复动作模板。

### 9.3 阶段间分布断层

如果第一阶段几乎全是无接触随机孔位，第二阶段几乎全是固定孔位碰撞，模型可能把“孔位是否变化”和“是否发生接触”错误地绑定在一起。

缓解方法：

- 第一阶段加入少量接触样本；
- 第二阶段保留部分孔位变化数据；
- 最后进行包含“新孔位 + 接触恢复”的联合微调。

## 10. 验证方案

至少应分别评估以下四种场景：

| 测试条件 | 主要验证目标 |
| --- | --- |
| 已见孔位 + 无碰撞 | 基本接近与插入能力 |
| 未见孔位 + 无碰撞 | 视觉泛化能力 |
| 已见孔位 + 碰撞 | 力反馈恢复能力 |
| 未见孔位 + 碰撞 | 视觉与力觉协同泛化能力 |

其中，“未见孔位 + 碰撞”是最关键的综合测试。只有模型在未见孔位发生碰撞后仍能完成恢复，才能说明它组合使用了视觉信息和力反馈，而不是分别记住两套固定模式。

还应进行以下模态消融：

1. 屏蔽力输入后，碰撞恢复性能是否明显下降；
2. 保留力输入但改变孔位后，策略是否仍能给出局部正确的修正动作；
3. 在相似视觉观测下施加相反方向的接触力，模型是否输出相应不同的动作；
4. 打乱力反馈的时间顺序后，恢复性能是否下降；
5. 只保留视觉或只保留力反馈时，模型分别能够完成哪些任务阶段。

如果屏蔽、打乱或替换力反馈后性能几乎不变，通常意味着模型没有真正利用力反馈。

## 11. 推荐的实施顺序

```text
1. 大范围孔位随机化，训练视觉定位和粗对准
2. 固定或小范围抖动孔位，密集采集可恢复接触
3. 第二阶段混入视觉数据，并保护视觉编码器
4. 逐步扩大孔位、姿态和接触物理属性的变化范围
5. 使用视觉与接触混合数据进行联合微调
6. 通过四种测试组合和模态消融验证模型是否真正使用力反馈
```

最终目标不是让模型分别记住“随机孔位下如何接近”和“固定孔位下如何碰撞恢复”，而是让它形成一条统一策略：

> 先利用视觉建立相对位姿和完成粗对准，再利用力反馈识别局部接触状态并进行闭环修正，最终在未见过的孔位和接触条件下完成插入。
